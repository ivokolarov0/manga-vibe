Remote control

An assistant (Claude, or any app that speaks MCP, the Model Context Protocol) can use MangaVibe for you: search and filter the library, open a series, read, turn pages, change settings, and use any button on a screen where MangaVibe is open. It acts as you: it sees your libraries and can do only what you can. For voice control, the Manga Accessibility plugin builds on this.
