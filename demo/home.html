Good to know

Before you install

Fully vibe coded

Every line was written by an AI assistant (Claude). It's tested, but has had no security audit: keep it on your home network, and keep backups.

Your files stay yours

Only Delete series and the Optimize plugin change files, and only when you ask. Mount the folder read-only (:ro) to rule both out.

For manga you own

MangaVibe doesn't include, download or share any manga. Please support the creators: buy what you read.

For developers

Ten lines to your first plugin

Python on the server, HTML, CSS and JavaScript on the page. The built-in plugins use the same API as yours.

Plugin API %API_VERSION%

plugins/hello.py
# shows up in Settings → Plugins
from app.plugins import Plugin

class Hello(Plugin):
    id = "hello"
    name = "Hello"
    version = "1.0.0"
    description = "Says hello in the log."
